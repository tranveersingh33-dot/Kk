Calculation Rules

  1. Bracket ke pehle wale sabhi numbers ko count kiya jayega.
  2. Bracket ke andar di gayi value se multiply kiya jayega.
  3. Agar bracket ke baad "wp" likha ho to bracket value double ho jayegi.
  4. Single ( ) ya double (( )) dono bracket valid hain.
  5. Saare groups ka total hi final total hoga.
Example:
23,45,67(10 = 3 x 10 = 30
23,45,67(10wp = 3 x 20 = 60
